## 环境准备
- **Windows 10/11 + Visual Studio 2022 或 2026**，勾选"使用 C++ 的桌面开发"，包含 CMake 与 vcpkg 组件。
- **`VCPKG_ROOT` 环境变量**指向 vcpkg 根目录，最省事的做法是用 VS 自带的：
  ```powershell
  [Environment]::SetEnvironmentVariable('VCPKG_ROOT', 'C:\Program Files\Microsoft Visual Studio\18\Community\VC\vcpkg', 'User')
  ```
  写完需要新开 shell（或重启 IDE）才生效。
- **OpenGL 4.6 驱动**：默认 GPU 路径与 CPU 参考路径都通过 GL 窗口呈现；`--hidden` 只是隐藏窗口，不是无显示服务。
- **CMake 版本**：`Visual Studio 18 2026` 生成器只有 VS 自带的 CMake 4.3+ 才认识，系统单独装的 CMake 3.27 会报生成器无效。
- 自动验证额外需要 **Python 3 + Pillow**。

## 获取代码与依赖
依赖全部由 `vcpkg.json` 声明，无需手工下载 OpenCV/GLFW/glad/ImGui：
- `opencv4`（仅 `core`/`imgproc`/`imgcodecs`，特性 `jpeg`/`png`/`thread`）
- `glfw3`、`glad`（`gl-api-46`）、`imgui`（`glfw-binding`/`opengl3-binding`/`docking-experimental`）
- 基线锁定 `b3df23b9d6fd69a3ce8fe8ccf943079bcc1499ad`

仓库不含 `build/` 与 `vcpkg_installed/`（均被 `.gitignore` 排除），首次配置会重新生成并下载依赖。

## 配置与构建
在仓库根目录执行（PATH 上的 cmake 过旧时用 VS 自带的绝对路径）：
```powershell
$cmake = "C:\Program Files\Microsoft Visual Studio\18\Community\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\cmake.exe"
& $cmake --preset vs2026
& $cmake --build --preset vs2026-release
```
- 预设：配置 `vs2026` / `vs2022`；构建 `vs2026-release` / `vs2026-debug`（`vs2022-*` 同理）。
- 生成目录 `build/<preset>/`，产物在 `build/vs2026/Release/`；VS 2026 生成 `MooLab.slnx`，VS 2022 生成 `MooLab.sln`。
- 首次配置要拉 vcpkg registry 并编译 OpenCV，耗时可达十几分钟；后续增量配置只需数秒。
- 也可在 VS 中"打开本地文件夹"选仓库根目录、配置预设 `vs2026`、启动项 `MooLab.exe`。

默认构建产出 `MooLab.exe`（主程序）与 `MooImageDiff.exe`（对拍工具）；`SceneProbe`、`FootContactBake`、`gl_probe`、`MaterialProbe` 标了 `EXCLUDE_FROM_ALL`，需要时显式构建：
```powershell
& $cmake --build --preset vs2026-release --target SceneProbe
```

## 运行
```powershell
& .\build\vs2026\Release\MooLab.exe
```
- 窗口为 1600×900 停靠式编辑器：左场景大纲、中 Viewport（离屏 720×720 等比留边）、右属性、底部播放/仿真、Motion Matching、统计页签。
- 键盘：WASD 移动（按相机水平朝向）、方向键环绕相机、空格暂停/继续、`.` 单步；XInput 手柄左摇杆移动、右摇杆相机；ESC 或关窗退出。
- 命令行参数：
  - `--frames N` 运行 N 帧后退出
  - `--capture-frame N PATH` 第 N 帧存图（从 0 开始，可重复，不含 ImGui）
  - `--renderer gpu|cpu` 默认 gpu
  - `--scene physics|motion-matching` 默认 physics
  - `--hidden` 隐藏窗口（仍需要 GL 上下文）
  - `--unlimited-fps` 取消 60 帧节流
  - 缺值或非法值一律非零退出
- 降低 CPU 占用（可选，程序未写死默认）：`$env:OMP_WAIT_POLICY='PASSIVE'`，恢复用 `Remove-Item Env:\OMP_WAIT_POLICY`。

## 首次验证
```powershell
& .\build\vs2026\Release\MooLab.exe --renderer cpu --hidden --frames 301 --unlimited-fps --capture-frame 60 cpu_060.png --capture-frame 300 cpu_300.png
& .\build\vs2026\Release\MooLab.exe --renderer gpu --hidden --frames 301 --unlimited-fps --capture-frame 60 gpu_060.png --capture-frame 300 gpu_300.png
& .\build\vs2026\Release\MooImageDiff.exe gpu_060.png cpu_060.png
& .\build\vs2026\Release\MooImageDiff.exe gpu_300.png cpu_300.png
```
期望两条 `MooImageDiff` 都退出 0；负对照 `gpu_060.png` vs `cpu_300.png` 必须失败。未接手柄时 CPU 60/300 帧 SHA-256 前 16 位应为 `F32E92295DFD7FFF` / `6CC141F39195243E`（OpenCV 4.14.0 实测；`foot_contacts.bin` 重烘焙后与 1.x 的 `004F883938E6AD0A` / `EB3E20DCBC32FF56` 不同）。全量验证：
```powershell
python Tools\Verify\verify_gl.py capture
```

## 常见问题
- **找不到 vcpkg / 工具链文件**：`VCPKG_ROOT` 未设或未开新 shell；确认 `$env:VCPKG_ROOT` 有值。
- **生成器无效**：用 VS 自带的 CMake，而不是系统 CMake 3.27。
- **首次配置卡在拉 registry**：GitHub 直连受限时需要给 git 配代理；大 pack 经代理挂起时同时设 `http.version=HTTP/1.1`、`http.lowSpeedLimit=1000`。
- **启动后提示资源目录不存在**：`MOOLAB_RESOURCE_DIR` 指向的源码目录被移动或改名，重新配置并编译即可；缺失时会回退到工作目录相对的 `../resources/`。
- **着色器打开/编译失败**：程序明确报错退出；检查 `Shaders/` 是否完整、是否移动过工程（宏里存的是配置时的绝对路径）。
