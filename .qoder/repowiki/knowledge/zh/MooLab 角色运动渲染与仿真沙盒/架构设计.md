分层模块化工程（每模块 `Public`/`Private`，由 `moo_module` 生成静态库），依赖方向单向：

- `Runtime/Core`（INTERFACE，`Core.h`/`GlContext.h`/`ViewportTexture.h`）：GL 上下文所有者契约与视口纹理描述，不含 GL、窗口与旧数学头。
- `Runtime/RHI`（`GlRhi`）：GL 对象 RAII、时间戳查询、着色器文件读取（`MOOLAB_SHADER_DIR`）。
- `Runtime/Renderer`：`RenderTypes`（纯数据）、`GpuRenderer`（GPU 路径）、`CpuImagePresenter`（CPU 8 位量化与呈现）、`PbrShading`（CPU 参考着色）。
- `Runtime/ApplicationCore`：`Platform`（XInput 手柄、帧节流）、`AppWindow`（GLFW + GL 上下文 + ImGui 生命周期）、`Input`（键鼠采集与输入路由）。
- `Runtime/Animation`：纯数据算法 `FootContacts`（逐脚接触标签的读写与校验）、`TwoBoneIk`，不依赖 GL 与 Legacy。
- `Sandbox`：`SandboxScene`（PImpl 门面，唯一包含 `Source/Legacy/*.hpp` 的编译单元）+ `SceneRender.inl`/`MotionMatching.inl`/`FootIk.inl`（`HEADER_FILE_ONLY`，仅由门面包含）+ `SceneTypes`（公共纯数据）。
- `Editor`：`EditorUi` 停靠式编辑器，只用 Sandbox 的公共纯数据与 ImGui。
- `Launch`：`Main.cpp` + `Application`（窗口/帧节拍/输入路由/截图/命令行参数组装）。
- `Legacy`：1.x 的数学/动画/物理/CPU 渲染 `.hpp`（`vec`/`mat`/`quat`/`array`/`camera`/`mesh`/`model`/`material`/`renderer`/`motion`/`ik`/`curve`/`simulator`/`robot`/`spring`/`strategy`/`database`/`nnet`/`texture`/`ui`/`character`/`controller`/`global`），含非 inline 定义，只能被 `SandboxScene.cpp` 包含。

依赖方向：`Renderer → RHI/Core`；`ApplicationCore → Core`；`Sandbox → Renderer/Core (+ OpenCV, OpenMP)`；`Editor → Sandbox公共数据 + ImGui`；`Launch` 组装出 `MooLab.exe`。运行链路：窗口与 GL 上下文 → 场景（FK/蒙皮/仿真在 CPU，顶点变换与光栅在 GPU）→ GpuRenderer 或 CpuImagePresenter → 呈现到默认帧缓冲 → ImGui 绘制编辑器。资源与着色器路径由编译期宏固定为源码目录的绝对路径，进程工作目录不变。
