**环境**：Windows + VS 2022 或 2026（含"使用 C++ 的桌面开发"、CMake、vcpkg 组件）；`VCPKG_ROOT` 指向 vcpkg 根（可直接用 `<VS>\VC\vcpkg`，建议写 User 级环境变量）；需要 OpenGL 4.6 驱动。VS 2026 生成器 `Visual Studio 18 2026` 只被 VS 自带 CMake 4.3+ 识别，系统独立安装的 CMake 3.27 会报生成器无效。

**构建（仓库根目录）**
```powershell
# 若 PATH 上的 cmake 版本过旧，用 VS 自带的
$cmake = "C:\Program Files\Microsoft Visual Studio\18\Community\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\cmake.exe"
& $cmake --preset vs2026                # vs2022 同理
& $cmake --build --preset vs2026-release
```
首次配置会下载 vcpkg registry 并编译 OpenCV 等依赖，耗时可达十几分钟；产物在 `build/vs2026/Release/`，DLL 自动部署。VS 中打开仓库根目录、选预设 `vs2026`、启动项 `MooLab.exe` 等价。

**运行**
- 默认 GPU 路径；`--renderer cpu` 切 CPU 软光栅参考路径；`--scene motion-matching` 直接进 MM 场景。
- 自动验证常用参数：`--frames N`、`--capture-frame N PATH`（可重复）、`--hidden`、`--unlimited-fps`。
- 低 CPU 占用（可选，程序未写死）：`$env:OMP_WAIT_POLICY='PASSIVE'`，恢复用 `Remove-Item Env:\OMP_WAIT_POLICY`。

**对拍与验证**
```powershell
& .\build\vs2026\Release\MooLab.exe --renderer cpu --hidden --frames 301 --unlimited-fps --capture-frame 60 cpu_060.png --capture-frame 300 cpu_300.png
& .\build\vs2026\Release\MooLab.exe --renderer gpu --hidden --frames 301 --unlimited-fps --capture-frame 60 gpu_060.png --capture-frame 300 gpu_300.png
& .\build\vs2026\Release\MooImageDiff.exe gpu_060.png cpu_060.png
python Tools\Verify\verify_gl.py capture    # 需 Python + Pillow
```
`MooImageDiff` 退出码：0 通过、1 阈值失败、2 输入错误、3 尺寸不一致；阈值差 ≤3 占比 ≥99%、差 >32 占比 ≤0.5%。负对照 `gpu_060.png` vs `cpu_300.png` 必须失败。`SceneProbe`、`FootContactBake`、`gl_probe`、`MaterialProbe` 为 `EXCLUDE_FROM_ALL`，需 `--target`（如 `--target SceneProbe`）才构建。
